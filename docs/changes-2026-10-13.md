# 2026-10-13 更新说明

本次更新修复全国岗位表导入、首次画像填写、岗位匹配和认证边界问题，并增加自动回归检查。

## 全国岗位表导入

- 使用部门代码和职位代码共同区分岗位，避免不同部门重复使用职位代码导致岗位被误判为重复。
- 正确映射部门名称、用人司局、职位名称和部门代码，减少说明文字对表头识别的干扰。
- 识别国考类型，按每行工作地点解析省份；多省地点保留为全国范围，避免将整张表归入上传时选择的同一省份。
- 部门代码贯通岗位、分数线、报名数据和成绩样本关联；代码存在歧义时要求补充条件。
- 重复导入时，相同记录跳过，内容变化的记录更新；仅有更新的任务也可正常完成。
- 保留有效的行级年份；岗位、报名和历史分数按地区、考试、年份及部门范围关联。
- 数据目录使用实际导入的最新年份，支持后续年度岗位表。

## 画像与岗位筛选

- 首次使用时无需导入岗位即可选择目标省份，目标城市可直接输入并保存。
- 补全画像的学位、政治面貌和基层年限，保存后可重新加载并用于筛选。
- 修复学历条件、不限专业和事业单位类型识别；专业目录按数据范围匹配。
- 已知资格冲突的岗位排除，信息不足或复杂条件列为待核验。
- 推荐年份留空时采用各省份、各考试类型最新已导入年份，也支持指定历史年份。

## 认证、数据与运行

- 开启正式认证后，导入和 Agent 接口要求登录；开发登录默认关闭，正式认证模式始终禁用开发登录。
- 导入数据属于已登录用户共享的工作区，当前版本没有租户级隔离。
- 清理预览、异常信息及嵌套字段中的敏感数据，统一数据集读取与删除范围。
- 删除导入任务时安全处理所属上传和预览文件，保留外部文件。
- 上传解析和同步分析移到线程池，限制上传大小，并为模型调用设置超时与整体分析预算。
- 提供 Windows 本地启动、停止脚本；使用方式见 [本地使用说明](../本地使用说明.md)。
