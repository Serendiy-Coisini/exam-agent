# 分析师的公开选岗方法

工作台默认将 [wangyou-honglingjin-perspective](https://github.com/tyf152119-web/wangyou-honglingjin-perspective) 的公开方法用于模型岗位推荐、岗位卡片解释、选岗策略和自由咨询中的公考复盘。打开侧边栏“模型设置”，在“分析方法”中查看加载状态和版本；模型仍使用你已配置的服务商与 API Key。

方法包括先筛硬条件、比较候选差异、区分事实与推断、结合个人约束、安排备选路径，以及给出下一步与停止条件。回答提供判断依据与行动建议，不展示内部推理，也不扮演或代表本人。

专业目录和确定性的资格筛选优先；模型不能扩大可报专业范围、把“待核验”说成已符合，或改动后端岗位列表。历史分数使用招考年度，不能把2026国考因笔试在2025年举行而改称2025年度。待遇、竞争与最新政策缺少证据时必须说明未知。

分数记录查询、政策检索和全量画像资格筛选继续使用各自的数据流程；skill 不替换这些流程，也不自行联网查公告。未配置模型或接口失败时，工作台返回原有规则回答，不声称已由模型分析。文件缺失、版本信息不符或内容校验失败时，状态显示未加载，模型使用通用准确性规则。

可以在对话中要求“不用这个方法”或“切回正常”；模型提示词要求尊重最近的对话选择。此偏好随对话上下文传递，不是跨会话保存的设置；准确性和资格规则始终生效。
