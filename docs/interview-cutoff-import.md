# 面试名单中的岗位进面分数线导入

支持把包含“最低面试分数”的官方面试人员名单识别为进面分数线表。该字段是岗位进入面试的官方最低分，不能当作名单中每位考生的个人面试成绩。

导入时按年份、考试类型、范围、部门代码和职位代码汇总。同一岗位在各工作表中的最低分必须一致；出现不同分数、缺失或无效分数时，整组岗位记录排除，并提示核对原表。同一岗位的进面人数按准考证号去重统计；身份号码缺失时不推断人数。汇总后的分数线记录不保留姓名、准考证号和未映射原始字段。

预览分别展示“读取人员记录”和“汇总有效岗位”，正常的同岗位人员记录不会作为重复岗位报错。支持带单位注释的分数字段和已确认的双层表头。仅有个人笔试或面试成绩的名单仍按个人成绩表处理，不推算岗位最低线。

中央机关全国名单可自动补全“国考”和“全国”范围。原表没有工作地点时不猜测省市，请在“数据中心”查看全国分数线数据集，或在“分数线参考”选择全国/全部范围查询。指定广东等单个省份不会包含这份无地理信息的全国名单。不同年度的数据保留各自年份，不将历史线自动标作新年度岗位的精确进面线。

验证覆盖识别、个人成绩区分、部门隔离、无效和冲突分数、跨工作表汇总、人数去重、注释及双层表头、隐私和重复确认。完整规模验证读取 113,377 条人员记录，汇总 20,227 个岗位；各岗位官方最低分和人数均与独立读取原表后的统计一致。实际原表及本地数据库不随代码发布。
