# 分析师的城市范围

城市选择是推荐的硬性范围。例如画像城市为汕头时，不会因专业适配、招录人数、接受异地或当地结果不足，补入湛江等外市岗位。没有工作地点明确且符合当前条件的本地候选时，返回缺口说明，等待用户明确调整地区。

“按我的画像推荐”采用已保存的画像城市；画像城市为空时，保留分析师当前已选城市。省份选项加载期间的新城市输入不会被迟到的响应清空，其他省份的旧响应也不会覆盖当前城市。

后台按工作地点字段判断范围，不把招录机关或用人单位名称当作工作地点证据。例如机关名称含“汕头海关”，工作地点在汕尾时，不属于汕头范围。多个工作地点或城市无法确认的岗位，不会被当成单一城市的确定推荐。

导入表中的明确行政工作地点也用于识别城市别名，因此无私有地区 CSV 时，仍可识别导入数据内的“广东省汕头市”和“汕头”。别名只依据已导入的工作地点，不推测机构管辖范围或城市之间的距离。

仅明确要求“附近”或“周边”，且项目存在已知邻接关系时，才允许相应周边城市；“本地”“家在”“通勤”“就近”以及“不考虑周边”不会自动扩大范围。没有邻接或距离数据时，不以同省替代附近。

城市范围先由代码筛选，随后模型使用已接入的公开选岗方法解释候选与风险。修改城市只改变地区范围，不能为凑推荐放宽专业、学历或其他报名资格。推荐解释仍应结合画像核验结果与岗位原始要求确认。

分析师的岗位准入与画像选岗共用严格专业目录和备注资格核验。相关专业词不能替代目录匹配；性别、证书、户籍、服务项目等明确冲突均排除。待核验项随候选传给模型，卡片不能把它改写成整体可报。
