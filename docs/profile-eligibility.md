# 按画像筛选全部岗位

在“我的画像”填写基础条件、专业目录信息，以及性别、毕业年份、应届范围、实际户籍省/市/县区、基层工作年限、服务基层项目经历、法律职业资格 A 类、英语四/六级成绩或合格证明、其他证书。目标省市是选岗偏好，实际户籍单独填写。其他证书请写完整名称和等级，用分号或换行分隔。

服务项目支持大学生村官、特岗教师（农村义务教育阶段学校教师特设岗位计划）、三支一扶、西部计划（大学生志愿服务西部计划）、高校毕业生退役士兵。项目期满、考核合格、服务年限、退役身份、高校毕业生身份、军队服役年限分别填报；五年服役门槛不会用基层年限替代。完整填报项目后勾选“已完整填写服务基层项目”；没有项目可留空并勾选，未勾选的空名单表示未知。

应届范围区分招录当年应届、保留应届资格和非应届。招录当年应届同时核对岗位年份与毕业年份，不固定写死 2027；保留应届资格不会满足“仅限招录当年应届”。复杂择业期、就业状态、生源认定保留待核验。A 类证书单独选“有/没有/未填写”，B/C 类不代替 A 类。

证书信息未填时，系统保留相关岗位为待核验。确认已完整填写时勾选“已完整填写证书信息”，未列出的证书视为没有；如果没有任何证书，可以留空并勾选。零分与未填写分数分别处理。

从侧边栏 **画像选岗** 或分析师页 **按画像筛选全部岗位** 进入：

1. 点击“重新读取画像”加载当前浏览器中的画像；需要长期修改请返回“我的画像”保存。
2. 选择省市、考试和年份。省市为严格范围，不补充邻近城市；多省或工作地点不明确的岗位会提示待核验。年份留空时按各省份、各考试类型取最新已导入年份。
3. 可在本页临时修改专业、户籍、基层年限、项目、应届、性别、英语及证书资格，勾选“启用备注资格核验”。临时修改不会覆盖已保存画像。
4. 点击“按画像筛选全部岗位”。新查询扫描完整已导入范围，结果按 20/50/100 条分页，不受分析师最多 5 个推荐岗位的限制。
5. 继续用专业限制层级（不限、门类、专业类、具体专业、混合限制、未识别）、岗位关键词、备注必须包含、备注排除关键词及结果状态复筛。多个备注关键词用分号或逗号分隔：包含条件需全部满足，排除条件命中任一词即排除。

结果分为三类：

| 状态 | 含义 |
| --- | --- |
| 条件匹配 | 已实现的规则没有发现冲突或待核验项，仍需核对官方公告 |
| 待核验 | 画像未填、目录缺失/代码名称冲突/未收录专业、地点不明确、复杂身份、未知备注或替代条件等 |
| 明确不符合 | 至少有一项可判断的资格冲突，可展开查看依据 |

默认同时显示“条件匹配 + 待核验”，也可单独查看各类及全部结果。每个岗位保留部门代码、职位代码、原始备注和逐条判断依据，跨部门同职位代码不会合并。

已覆盖的备注规则包括明确的男/女性限制、CET4/CET6 各自的分数门槛与合格证明、英语条件中的“或/且”组合，以及法律职业资格、注册会计师、会计专业技术、软考、教师资格、医师/护士、普通话、驾驶证等常见证书名称。未知证书、不同证书/等级的替代关系、建议/优先/否定/复杂条件分支保留待核验；不会仅凭关键词命中就判定满足。

“425 分及以上”包含 425 分；“高于/超过 425 分”不包含 425 分。四级、六级分别核验，不自动用六级替代四级，也不把“没有填写”当成不具备。英语专业四/八级、雅思、托福等尚未建立专用规则，会显示原文待核验。

这是基于已导入字段与文本的辅助初筛，不能替代官方资格审查。备注中的复杂条件以及年龄、体检体测、工作经历和应届资格的具体认定仍须核验。户籍只按明确省市县区核验，本地范围或多地工作地点不明确时保留待核验。当前全量出口读取已入库的 SQLite 岗位；需要先确认职位表已入库，单纯上传预览不会进入结果。

该功能不调用模型、不向外部服务发送画像或岗位，不改写岗位数据。开启正式认证后接口要求登录，画像按当前用户读取；岗位仍属于工作台共享数据。

## 严格专业目录

当前本机依据用户指定《普通高等学校本科专业目录2026版.pdf》（31 页）建立本地目录：13 个门类、92 个明确专业类、883 个专业。每条保留原始代码（包括七位代码和 T/K/TK 后缀）、门类、专业类、来源页码及注释；原文未给专业类的交叉学科专业不补造分类。

所有目录专业使用同一套从小到大的匹配顺序：先确定画像的具体专业，再上溯所属专业类、所属门类，最后包括专业不限。比如软件工程（080902）可匹配软件工程、计算机类、工学及专业不限岗位。具体专业限制与画像不符时，不能因同属计算机类或工学就放行；岗位另列可选专业类/门类时，才继续匹配该分支。多个可选分支优先比对具体专业，再专业类、门类及不限；保留岗位括号细分和排除项的限制。目录没有专业类的记录不补造层级。

多专业并列时，每个可选分支分别核验；一个分支不符不会排除另一个可匹配分支。括号细分不能掩盖已明确的外层冲突，未知分支或可能扩大范围的描述仍保留待核验。本科与研究生按各自段落核验。

在“我的画像”选择目录学历、门类、专业类并填完整专业名，或输入完整代码。例如软件工程（080902）属于计算机类（0809）、工学（08），可匹配这三个限制层级以及专业不限；不会用“软件”“计算机”等片段或相似专业名自动扩大范围。专业名与代码、手填层级发生冲突时保留待核验。岗位同时列本科/研究生专业时，只判断对应学历段；本目录仅适用于普通本科，专科及研究生不会借用本科分类。

服务端从 `data/major_catalog.json` 加载经过校验的本地结构化目录，登录后通过 `/api/v1/jobs/major-catalog` 读取；文件更新后自动按修改时间重新载入。该目录 JSON 和原始 PDF 不随代码推送。目录丢失、元数据无效或层级矛盾时，受专业限制的岗位保留待核验，专业不限仍可正常核验。页面会显示目录文件名、专业数和匹配专业的来源页码。

“与最高学历相对应的学位”按画像学历与学位的对应关系核验，如本科对应学士、硕士研究生对应硕士。学历或学位未明确时保留待核验；不会将整句描述当成学位名称而误排除。
