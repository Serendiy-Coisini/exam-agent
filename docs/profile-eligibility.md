# 按画像筛选全部岗位

在“我的画像”填写基础条件，以及性别、毕业年份、英语四/六级成绩或合格证明、持有证书。证书请写完整名称和等级，用分号或换行分隔。

证书信息未填时，系统保留相关岗位为待核验。确认已完整填写时勾选“已完整填写证书信息”，未列出的证书视为没有；如果没有任何证书，可以留空并勾选。零分与未填写分数分别处理。

从侧边栏 **画像选岗** 或分析师页 **按画像筛选全部岗位** 进入：

1. 点击“重新读取画像”加载当前浏览器中的画像；需要长期修改请返回“我的画像”保存。
2. 选择省市、考试和年份。省市为严格范围，不补充邻近城市；多省或工作地点不明确的岗位会提示待核验。年份留空时按各省份、各考试类型取最新已导入年份。
3. 可在本页临时修改性别、英语及证书资格，勾选“启用备注资格核验”。临时修改不会覆盖已保存画像。
4. 点击“按画像筛选全部岗位”。新查询扫描完整已导入范围，结果按 20/50/100 条分页，不受分析师最多 5 个推荐岗位的限制。
5. 继续用岗位关键词、备注必须包含、备注排除关键词及结果状态复筛。多个备注关键词用分号或逗号分隔：包含条件需全部满足，排除条件命中任一词即排除。

结果分为三类：

| 状态 | 含义 |
| --- | --- |
| 条件匹配 | 已实现的规则没有发现冲突或待核验项，仍需核对官方公告 |
| 待核验 | 画像未填、专业大类/近似专业、地点不明确、复杂身份、未知备注或替代条件等 |
| 明确不符合 | 至少有一项可判断的资格冲突，可展开查看依据 |

默认同时显示“条件匹配 + 待核验”，也可单独查看各类及全部结果。每个岗位保留部门代码、职位代码、原始备注和逐条判断依据，跨部门同职位代码不会合并。

已覆盖的备注规则包括明确的男/女性限制、CET4/CET6 各自的分数门槛与合格证明、英语条件中的“或/且”组合，以及法律职业资格、注册会计师、会计专业技术、软考、教师资格、医师/护士、普通话、驾驶证等常见证书名称。未知证书、不同证书/等级的替代关系、建议/优先/否定/复杂条件分支保留待核验；不会仅凭关键词命中就判定满足。

“425 分及以上”包含 425 分；“高于/超过 425 分”不包含 425 分。四级、六级分别核验，不自动用六级替代四级，也不把“没有填写”当成不具备。英语专业四/八级、雅思、托福等尚未建立专用规则，会显示原文待核验。

这是基于已导入字段与文本的辅助初筛，不能替代官方资格审查。备注中的复杂条件以及年龄、户籍、体检体测、工作经历的具体认定仍须核验。当前全量出口读取已入库的 SQLite 岗位；需要先确认职位表已入库，单纯上传预览不会进入结果。

该功能不调用模型、不向外部服务发送画像或岗位，不改写岗位数据。开启正式认证后接口要求登录，画像按当前用户读取；岗位仍属于工作台共享数据。
